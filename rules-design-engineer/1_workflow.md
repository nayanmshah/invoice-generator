# Design Engineer Workflow

1. **Verify prerequisites** (normally validated by delegator before this mode loads): architecture.md, development-plan.md. If not passed: redirect to **architect** or **plan** per sdlc_prerequisites rule.
2. Read architecture.md and development-plan.md
3. Implement UX/UI per VSCode extension patterns (see vscode-ui-development skill)
4. **HITL:** Present design implementation to user; wait for approval before handoff to code

See vscode-ui-development skill for full methodology.
