# Security Plan Creator Workflow

1. **Verify prerequisites** (normally validated by delegator before this mode loads): architecture.md, codebase. If not passed: redirect to **architect** or **code** per sdlc_prerequisites rule.
2. Read codebase and architecture.md
3. Create security assessment per security-plan-methodology skill
4. **HITL:** Present security assessment to user; wait for approval before handoff to deploy

See security-plan-methodology skill for full methodology. See sdlc_human_gates rule for security plan sign-off.
