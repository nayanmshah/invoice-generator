# Security Plan Methodology

For workflow steps, see `.nayan/rules-security-plan-creator/1_workflow.md`. See sdlc_human_gates rule for security plan sign-off gate.

## When to Use This Skill

Use this skill when:

- Creating comprehensive security plans and policies
- Conducting threat assessments using STRIDE methodology
- Designing identity and access management frameworks
- Planning data protection and compliance measures

## When NOT to Use This Skill

Do NOT use this skill when:

- Implementing security controls in code
- Debugging security issues
- Writing tests

## Security Plan Methodology

### Phase 1: Security Assessment and Risk Analysis

**1.1 Threat Modeling and Risk Assessment**

- Conduct comprehensive threat modeling using STRIDE methodology
- Identify and document all threat vectors and attack surfaces
- Assess business impact and likelihood of threats
- Create risk matrix with severity and probability ratings
- Document threat actors and their capabilities
- Create risk mitigation strategies and controls

**1.2 Asset Inventory and Classification**

- Create comprehensive asset inventory and classification
- Document data classification and sensitivity levels
- Identify critical assets and dependencies
- Create asset protection and monitoring strategies

**1.3 Compliance Requirements Analysis**

- Identify applicable compliance frameworks (GDPR, HIPAA, SOC2, PCI-DSS)
- Document compliance requirements and obligations
- Assess current compliance posture and gaps
- Create compliance mapping and control framework

### Phase 2: Security Architecture and Design

**2.1 Security Architecture Design**

- Design defense-in-depth security architecture
- Define security zones and network segmentation
- Document access control and authentication architecture
- Design encryption and data protection architecture

**2.2 Identity and Access Management**

- Design authentication and authorization framework
- Define user provisioning and deprovisioning processes
- Document role-based access control (RBAC) implementation
- Design multi-factor authentication (MFA) strategy
- Define privileged access management (PAM)

**2.3 Data Protection and Privacy**

- Design data classification and handling procedures
- Define data encryption strategies and key management
- Document data retention and disposal policies
- Design data privacy and GDPR compliance framework

### Phase 3: Security Controls and Implementation

**3.1 Technical Security Controls**

- Design network security controls and firewalls
- Define endpoint security and device management
- Document application security controls and WAF
- Design database security and access controls
- Define API security and rate limiting

**3.2 Administrative Security Controls**

- Design security policies and procedures
- Define security awareness and training programs
- Document security incident response procedures

### Phase 4: Security Monitoring and Incident Response

**4.1 Security Monitoring Strategy**

- Design SIEM implementation
- Define security monitoring tools and technologies
- Document threat detection and response automation

**4.2 Incident Response Framework**

- Design incident response team structure and roles
- Define incident classification and severity levels
- Document containment, eradication, and recovery procedures

**4.3 Business Continuity and Disaster Recovery**

- Design business continuity planning
- Define disaster recovery strategies
- Document failover and redundancy strategies

### Phase 5: Security Governance and Compliance

**5.1 Security Governance Framework**

- Design security governance structure and roles
- Define security policies and standards

**5.2 Security Compliance Management**

- Design compliance monitoring and reporting
- Define compliance audit procedures

### Phase 6: Security Awareness and Training

**6.1 Security Awareness Program**

- Design security awareness curriculum and content
- Define training delivery and methods

**6.2 Security Training and Development**

- Design role-based security training programs
- Define security certification and competency
