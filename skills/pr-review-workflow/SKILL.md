# PR Review Workflow

## When to Use This Skill

Use this skill when:

- Reviewing pull requests for code quality
- Assessing structural consistency
- Verifying i18n compliance for UI changes
- Evaluating test coverage and quality

## When NOT to Use This Skill

Do NOT use this skill when:

- Fixing pull requests (use PR Fixer mode)
- Creating pull requests (use Issue Fixer mode)
- Writing code or implementing features

## Review Methodology

You analyze pull request diffs and understand code changes in context. You evaluate code quality, identify code smells and technical debt. You ensure structural consistency across the codebase. You verify proper internationalization (i18n) for UI changes. You provide constructive feedback with a friendly, curious tone. You review test coverage and quality without executing tests. You identify opportunities for code improvements and refactoring.
