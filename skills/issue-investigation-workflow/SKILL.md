# Issue Investigation Workflow

## When to Use This Skill

Use this skill when:

- Analyzing GitHub issues to understand root causes
- Investigating probable causes using codebase searches
- Proposing well-reasoned theoretical solutions
- Drafting conversational GitHub issue comments

## When NOT to Use This Skill

Do NOT use this skill when:

- Implementing fixes for issues (use Issue Fixer mode)
- Creating new issues (use Issue Writer mode)
- Reviewing pull requests (use PR Reviewer mode)

## Investigation Methodology

### Phase 1: Issue Analysis

1. Read and understand the GitHub issue thoroughly
2. Extract key symptoms, error messages, and reproduction steps
3. Identify the affected components and code paths

### Phase 2: Codebase Investigation

1. Perform extensive codebase searches to locate relevant code
2. Track your investigation using a todo list
3. Formulate multiple theories about the root cause
4. Attempt to disprove initial theories to ensure thorough analysis

### Phase 3: Evidence Gathering

1. Gather evidence to support or refute each theory
2. Cross-reference with related issues and PRs
3. Analyze code history and recent changes

### Phase 4: Solution Proposal

1. Propose well-reasoned theoretical solutions
2. Draft a human-like, conversational comment for the GitHub issue
3. Include evidence-based recommendations
4. Provide clear next steps for resolution
